# El Creador v17

- Base v16 mantenida.
- Base mundial ampliada a exactamente 329 creadores.
- Países: Argentina, España, México, Colombia, Chile, Uruguay, Brasil y Estados Unidos.
- No hay perfiles clasificados como Música.
- Se eliminaron el minijuego anterior, su pantalla, ruta y acceso desde publicación.
- Publicar video continúa directamente al resultado trimestral hasta implementar el nuevo minijuego.
- Se agregaron 20 eventos de mundo/cultura/contingencia.
- Se ampliaron formatos y temas de videos.
- Se agregaron sponsors y equipamiento.
- Los nuevos creadores usan el mismo sistema de colaboraciones, crecimiento, rivalidades, noticias y simulación mundial.

- Corrección de simulación: las publicaciones automáticas ya no se comprimen para que el video destacado represente un porcentaje fijo del trimestre. Cada video aporta vistas/subs de forma independiente según la audiencia del canal.
- Los eventos de "Pasan cosas" se generan al cierre de cada trimestre y las oportunidades de colaboración tienen una probabilidad mucho mayor de aparecer.
- Las propuestas/eventos se abren automáticamente al terminar la publicación cuando existe una oportunidad pendiente; no hay que ir a buscarlas al menú.
- Colabs simplificado: el directorio solo muestra creadores a los que se puede proponer ahora y usa un único botón rojo "PROPONER COLAB".
- El resultado trimestral vuelve a mostrarse después de resolver las oportunidades pendientes.
