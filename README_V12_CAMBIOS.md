# El Creador v12

## Cambios
- Reemplazado el selector de minijuegos anterior por un Bottle Flip Challenge jugable con física 2D simple.
- 3 intentos por ronda; el aterrizaje dentro de la zona verde determina el resultado.
- El resultado del minijuego modifica vistas, suscriptores e ingresos del trimestre.
- Agregado sprite SVG local de iconos inspirado en Google Material Symbols/Material Icons para el HUD y acciones principales.
- Eliminado código JS, pantallas y carpetas que no forman parte del grafo de imports de la aplicación actual.
- Se mantienen los sistemas necesarios para el juego actual, incluyendo Firebase del panel admin.
