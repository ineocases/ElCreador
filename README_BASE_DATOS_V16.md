# El Creador v16 — Base de datos ampliada

Esta versión conserva el proyecto original y amplía su contenido sin reemplazar la arquitectura.

## Base incluida
- 329 creadores de contenido.
- Argentina como núcleo + España, México, Colombia, Chile, Uruguay, Brasil y Estados Unidos.
- Sin perfiles clasificados como Música.
- Gaming, Streaming, Variedad, IRL, Vlog, Fútbol, Tecnología, Comedia, Cocina, Educación, Documental, Podcast, Viajes y Fitness.
- Nuevos creadores ficticios para alimentar la progresión del mundo.

## Eventos
- 20 eventos nuevos, integrados al sistema `Pasan Cosas`.
- Se conservan los eventos originales.
- Las opciones siguen usando el sistema de consecuencias del juego.

## Generador de títulos
- 17 formatos de contenido.
- Nuevos nichos y temas.
- Se conservan los formatos originales.

## Sponsors
- Nuevas marcas y escalones de progresión.

## Equipamiento
- Nuevas cámaras, micrófonos, PCs, iluminación, capturadoras y accesorios.

Todos los archivos JavaScript fueron comprobados con `node --check`.
